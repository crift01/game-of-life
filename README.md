# The Game of Life

This program is a simple implementation of Conway's Game of Life. 
It is written using a restricted subset of C, specifically limiting myself to the concepts covered up to Lesson 7 of Salvatore Sanfilippo's course. 
While I am familiar with more advanced C features, I intentionally imposed this constraint as a learning exercise. 

Please note that the code is not fully optimized as i prioritized readability and demonstrating the core concepts over raw performance.

## How to Run

You will need a C compiler (like GCC or Clang) installed on your system. 

1. Clone the repository and navigate to the directory.
2. Compile the code:
   `gcc life.c -o gameoflife`
3. Run the executable:
   `./gameoflife`
